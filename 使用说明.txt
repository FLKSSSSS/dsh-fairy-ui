# dsh-fairy-ui 1.4.2

适用于用户提供的 **DeepSeek Harness 0.2.0-rc.2 Windows 原版构建**。保留原版账号、模型、语音设置、会话、权限及 Agent 预设；提供 Fairy / HDD 视觉界面及“安装语音模型”提示词按钮。

## 1.4.2 修复重发（2026-10-14）

**替换原 1.4.2 安装包，版本号不变。已安装旧包的用户也需要重新解压并运行新包安装脚本。**

- 修复发送／停止按钮继承透明工具栏 `pointer-events: none` 导致点击穿透到聊天输入区的问题；只恢复原按钮的点击响应，不接管发送逻辑、不强制启用禁用按钮。
- 修复原生上下文用量栏在输入卡片下方额外占一行造成底部大缝；上下文百分比移至输入区右上角，仍可点击查看详情。默认输入卡片保持 132px，不靠拉高解决。
- 修复附加文件后左右控制栏中间一排错位；保留加号、模型／强度选择、语音、比例、速度和原生交互。
- 安装和卸载改为定向离线操作，不调用 DSH 插件 CLI，不让 pnpm 重解析整个 profile，因此不再被其它插件的 `billion-context@0.1.197` 缺失版本阻断。
- 插件包持久化到 profile 的 `.fairy-local-packages`；替换同版本时核对实际文件，旧 1.4.2 内容也会更新。备份、失败回滚、未知宿主拒绝和运行中拒绝保护保留。
- 不删除其它插件、语音／模型设置或会话，不降低供应链校验策略。其它插件自己的版本问题仍须单独处理，本工具并未修复其 npm 发布。

### 原 1.4.2 功能与修复

- 按参考样式恢复模型选择与推理强度：模型菜单、搜索列表、蓝色强度文字和渐变滑条；只列出当前模型支持的强度，保留原生模型配置。
- 修复输入后模型栏消失、压缩及按钮溢出；加号、模型与发送按钮完整收在输入区内，窄窗口也保留加号。
- 去除输入框上方多余空行，默认高度仍为 132，不通过拉高输入框实现。
- 左侧工作区/模式/权限与右侧语音/比例/速度逐行对齐，随输入区拖动高度保持等距；修复拉高后灰色材质背景截成两段的问题。
- **新版启动结束淡入**：完成交互且 DSH 已加载时，原生启动覆盖层约 0.48 秒平滑淡出，下面已加载的主界面柔和显现。加载未完成仍保持终幕；不重新启动主窗、不重播。跳过/异常走直接揭示兜底，旧版视频不加此等待。
- 保留旧新版选择、播放/交互一次、75% 首屏标识、Fairy Agent、原语音模型设置与“安装语音模型”提示词按钮。

### 继承 1.4.1 的细节优化

- **首屏标识整体缩小为 1.4.0 的 75%**：HDD 图案、下方原字形文字及二者间距同时等比例缩小，保留透明黑白素材与长宽比。这是首屏的基准尺寸调整，不覆盖设置中的整舞台缩放比例。
- **去除旋转几何装饰圈**，保留与聊天界面同源的 Fairy 大眼睛与授权后的出现效果。
- 参考用户指定的《莱茵生命DeepSeekHarness启动动画》的入场节奏，用本地交互元素实现标题横向揭示、字幕细线展开、资料行/按钮/提示依次淡入与轻微位移。只参考动效，不嵌入、下载或分发参考视频与声音，也不复制其素材。
- 减弱扫描线、故障闪烁与终幕闪光，改善各页面文字直接跳出的突兀感；同一文字不重复触发入场，动效跟随速度设置。
- 终态连同伪元素动效一起冻结，支持系统减少动态效果偏好；优化效果不添加额外等待、不延长原流程。
- 继续保留旧新版选择、交互授权/身份确认、覆盖式并行加载、每次启动只跑一次、完成后保持终态直到宿主就绪。

### 继承 1.4.0 的交互功能


- **撤回 1.3.0**：GitHub 的该发布与标签已撤下，旧版本 1.2.0 保留；本地旧包只留作备份，不再推荐安装。
- **新版是真正可交互界面，不是视频**：纯本地 DOM / SVG / CSS，既不加载 MP4，也不播放声音。设置 → Fairy 启动动画 → 动画样式，选择“新版（HDD / Fairy · 无视频）”；旧版原视频仍是独立可选项，已有选择不会被强制更改。
- 开场用用户提供的 HDD 图案和下方文字倒影：白色透明素材，保留原字形、中文、横线与倒影，不重打成普通字体。背景参考旧版的深蓝黑底、白字、扫描与故障风格。
- 授权页左上显示 `HDD` / `HOLLOW DEEP DIVE ESYSTEM`。必须点击“授予访问权限”（也支持 Enter / Space），才通过闪烁与错误分片显示复用聊天界面 SVG 的 Fairy 大眼睛，并把左上 `HDD` 切换成 `FAIRY`。
- 身份页显示 **法厄同 / 0000 / 权限等级 3**。必须点击“确认身份”，才依次进入参考插件的接收访问需求、读取权限、核验通过、WELCOME 终幕。沿用后续步骤文字、顺序与停留节奏；视觉重新配色，终幕保留故障、光晕与短闪光，移除鲸鱼与语音；1.4.1 使用更轻的信号切换与短闪光。
- **点击只推进视觉流程**，不会真正登录、授权、读取账号权限或更改身份。按钮等待不受 90 秒保护超时影响；动画阶段仍保留故障兜底。步骤条是演出进度，真实 DSH 加载另行判断。
- 每次启动只跑一次；完成后固定终幕直到 DSH 已就绪，提前就绪不会越过两个确认按钮。提供“跳过”以直接结束视觉流程，但仍等待宿主加载完成。

### 保留 1.2.0 功能与修复

- **覆盖式启动**：启动覆盖层仍在后端加载前打开；主/欢迎窗口一创建就在动画下方加载与显示。动画是原生附属覆盖层，结束且界面就绪时仅移除覆盖，不关闭后再创建主窗口。
- 主窗口与覆盖层随移动/缩放同步，覆盖只位于本应用上方，不占用第二个任务栏入口。欢迎界面切换到主界面时复用同一个覆盖层，不重跑流程。
- **Fairy Agent 预设**：复用所给 Fairy 完整包的人格、语料、voice core、安全提示段和标准工具组成，新增可选 `Fairy`，不切换默认 Agent、不覆盖已有预设。已存在同 ID `fairy` 时保留原定义。
- 旧版原动画媒体与 HTML/CSS、初始尺寸（1320×900，最小 920×620）保留；不重编码视频。高 DPI 存在系统取整，避免尺寸反馈累积。
- 每次程序启动只播放一次、不循环；没有第 5 秒暂停。播完但加载未完成时保持最后一帧；提前加载完成也等完整播放，再移除覆盖层。
- 保留比例调节、手动预览、语音模型设置与“安装语音模型”草稿按钮。

## 安装/升级

[下载 1.4.2 Windows 完整安装包](https://github.com/FLKSSSSS/dsh-fairy-ui/releases/download/v1.4.2/dsh-fairy-ui-1.4.2-windows.zip) · [版本发布说明](https://github.com/FLKSSSSS/dsh-fairy-ui/releases/tag/v1.4.2)

1. 若原版从未启动过，先启动一次以初始化 desktop profile，再完全退出。
2. 完全退出 DSH（包括系统托盘）。安装脚本检测目标正在运行时会拒绝修改，不会强制结束进程。
3. 解压新下载的完整 Windows 包到独立目录（不要混用旧包文件），双击 **安装插件.cmd**。默认目标：`F:\Fairy测试\DSH原版对照`。
4. 其他目录使用下列命令；安装后重启原版 DSH。安装会把 tgz 保存到 profile 的 `.fairy-local-packages`，运行不再依赖解压目录；建议保留新包用于卸载／恢复。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "完整路径\install-plugin.ps1" -DshRoot "你的DSH目录"
```

从旧 1.4.2 更新到本次修复重发包可直接运行新包 **安装插件.cmd**，同版本内容也会替换；若宿主适配器状态属于旧构建并被拒绝，先运行新包 **恢复原版启动.cmd** 再安装。

从 1.1.0、1.1.1、1.2.0、已撤回的 1.3.0、1.4.0、1.4.1 或其他已安装原生适配器的版本升级：完全退出 DSH，先运行新包 **恢复原版启动.cmd**，再运行 **安装插件.cmd**。恢复启动不会移除视觉插件或改动语音设置。从仅安装网页插件的 1.0.0 升级可直接安装；旧包不要删除（其他 profile 可能仍引用）。
若启用了 dsh-fairy-visual 老皮肤，先禁用它；其他修改同一视觉的皮肤也建议禁用。脚本不会覆盖已有 Agent、修改默认 Agent 或其他插件。
脚本可指定 `-Profile desktop -DshHome "独立数据目录"`。默认遵循 DSH_HOME，未设置时为 `%USERPROFILE%\.dsh`，不自动切换至 Fairy 便携数据目录。

## 原生接入与兼容边界

**只在 DSH 插件管理安装 tgz，不能得到后端启动前的原生动画。**tgz 负责网页视觉、语音设置、Fairy 可选 Agent 预设和手动预览，完整脚本还会执行可恢复的桌面适配。

适配器只修改 `resources\app.asar` 的 Electron 主入口，外置资源放在 `resources\fairy-ui-startup`。备份：`resources\app.asar.fairy-ui-original`；状态：`resources\fairy-ui-startup-state.json`。不替换 exe、不禁用安全 fuse、不改账号、权限、模型配置；不分发原版完整 archive/入口。
安装前校验交付文件及原版 archive/入口 SHA256；相同版本号但构建不同也会拒绝。官方更新前建议先卸载/恢复，绝不能用旧备份强行覆盖已更新宿主。
原生适配对指定桌面安装整体生效；视觉插件按 profile 安装。
动画不再等待插件 HTTP 服务，但**不保证其他后台插件、网络、磁盘的加载耗时都缩短**。有意保留约 13 秒动画；加载较慢时在视频结束后保持最后一帧等待，不在中途暂停。

## 使用 Fairy Agent

启动后在**新对话的 Agent / 预设选择器**中选择 **Fairy**。若没有显示选择器，先在原版**设置 → 通用 → 显示代码工作视图**中开启该选项；插件不替你更改这个原版偏好。原版预设与默认选项仍在；不强制切换已有对话，已开始的对话受原版预设锁定规则约束，需要另建对话。
Fairy 人格和语料只在选中该预设的 Agent 中生效；这不是语音模型安装，不需要下载人格模型，也不捆绑语音权重。原版模型、账号、工具审批及宿主权限策略照常生效。
原预设内的 `runtimePath` 指向来源机器未分发的 Python 脚本且不被实际 JS core 使用，接入时移除了这个无效配置，改用插件随包 JS core 与语料的绝对模块路径。保留源文件以便对比。没有引入 Fairy 便携包的账号、会话重置、权限覆盖、`fairy-identity` 或未随该预设分发的世界知识检索模块。
若已有 `fairy` ID，不替换它；使用原有 Fairy。卸载只注销本插件注册的预设，不删用户预设。旧会话需要继续使用此插件提供的 Fairy 时不要卸载插件。

## 启动动画比例设置

设置 → **Fairy 启动动画**：先选择动画样式（旧版 / 新版），再调整比例与缩放。画面比例可选跟随窗口（默认）、16:9、16:10、4:3、1:1；画面缩放范围为 50%–150%，可选择填满画面或完整显示。支持恢复默认和立即预览；默认跟随窗口、100%、填满画面，与原显示效果一致。旧版比例相对于窗口，新版比例作用于整个交互舞台；仅改变动画区域，不改变主窗口尺寸。新版不使用视频的填满/完整显示和静音选项；速度只影响自动动效时间，不替代点击确认。恢复比例默认不重置所选样式。缩放超过 100% 或使用填满模式时可能裁剪，完整显示可能产生黑边，不拉伸视频。
更改会保存到本机，并在界面仍运行时同步到原生启动偏好（约一秒）；下次启动生效。请正常退出 DSH（包括托盘），不要强制结束进程。手动预览立即使用已保存设置。

## 卸载/恢复

完全退出 DSH，运行 **卸载插件.cmd**，定向移除所选 profile 的 Fairy 注册并恢复原版入口，不调用整 profile 依赖解析。原模块与配置备份保留在 `.fairy-uninstall-backups`；安装备份在 `.fairy-install-backups`。工具不删除会话、用户语音／模型配置、其它插件或共享缓存。
仅恢复启动且保留视觉插件：运行 **恢复原版启动.cmd**，不要求 profile 存在；也可使用 `-Action RestoreNative -DshRoot "目标路径"`。
恢复仅清理记录哈希仍匹配的自有资源，保留用户改动/新增文件。宿主或备份无法验证时拒绝覆盖。

## 安装语音模型按钮

设置 → 语音模型设置 → **安装语音模型**。按钮将安装提示词填入当前对话的真实草稿，保留已有文本、重复点击去重；不自动发送、不创建/切换会话。关闭设置、审阅提示词后点击原版发送，让 DSH 按你的网络、模型和审批权限执行安装。
没有活动对话时先进入对话；不支持的输入接口提供“复制安装提示词”兜底。
提示词限定本机 DSH_HOME/fairy-voice-data/voice-runtime 部署、核验可信来源、不改系统 Python/PATH、保留账号/人格/权限/历史、服务仅监听本机。
不捆绑 Python 或语音模型权重，不保证模型源可用；Fairy 专用音色需你有权使用的权重，不把通用音色冒充 Fairy。
保留自动朗读、语音状态、本地代理、参考音频/文本及可选云端摘要。默认参考 WAV 只在缺失时写入，不覆盖已有文件；新安装默认关闭自动朗读，已有明确偏好不强制覆盖。
