DSH 原版 Fairy / HDD 界面插件 1.0.0
适配并实测版本：DeepSeek Harness 0.2.0-rc.2
制作日期：2026-10-12

一、这是原版插件，不是 Fairy 独立程序
通过原版自带 plugin CLI 注册一个附加界面插件，无需替换 app.asar、exe 或原版运行库。安装包已携带自身运行依赖，可以离线安装插件；语音模型本身的安装另需网络或授权本地文件。

二、安装
1. 如果从未运行过原版 DSH，请先启动一次，让 desktop 配置初始化。
2. 如果已有 dsh-fairy-visual 老插件，请在 DSH 的插件管理先禁用它；其他修改同一界面的皮肤也建议先禁用。安装脚本发现旧 Fairy 视觉插件仍启用时会停止，不擅自修改旧人格或权限。
3. 完全退出 DSH，包括右下角托盘。双击本目录“安装插件.cmd”。
4. 安装脚本默认定位 F:\Fairy测试\DSH原版对照，只接受已验证的 0.2.0-rc.2。安装结束后重启原版 DSH。
5. 保持安装目录完整、不要移动或删除 tgz 文件。原版 package.json 将引用本地 tgz，后续重新解析依赖仍可能需要它。

如果 DSH 安装目录不同，可在 PowerShell 指定：
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install-plugin.ps1 -DshRoot "你的DSH目录"
默认使用原版 DSH_HOME 环境变量；未设置时使用 %USERPROFILE%\.dsh。不会自动切换到 Fairy 便携版的数据目录。
也可使用原版支持的本地插件包安装入口选择 dsh-fairy-ui-1.0.0.tgz。

三、“安装语音模型”按钮
设置 → 语音模型设置 → 安装语音模型。
按钮把安装提示词写入当前对话的真实输入状态，保留已有文本草稿，重复点击不重复添加。它不会自动创建/切换会话，也不会自动发送消息。
请关闭设置，审阅提示词，再点击 DSH 原版发送按钮。DSH 根据你已有的模型、网络和审批权限执行实际安装。
如果没有活动对话，请先打开工作区和对话。若输入接口不兼容，使用旁边的“复制安装提示词”手动粘贴。

提示词要求：检测本机 CPU/GPU 与磁盘，仅在 DSH_HOME/fairy-voice-data/voice-runtime 中部署；核验官方来源；不改系统 Python/PATH；保留模型、API Key、人格、权限与历史；服务仅监听 127.0.0.1:9880；实际测试后才报告完成。
Fairy 音色专用权重需要你有权使用的 .ckpt/.pth 或可信授权来源。没有授权权重时 DSH 应明确请你提供，不会把通用音色冒充 Fairy。
安装提示词不构成下载链接或模型可用性的保证，实际可用性取决于你提供的权重和运行环境。

四、保留的设置与新增视觉
保留：自动朗读、语音状态刷新、参考 WAV/对应文本上传、可选云端朗读摘要设置；保留原版“模型”“Agent 预设”等设置。
新增：HDD / Fairy 视觉设置，深/浅色、低功耗、Fairy 尺寸和动画速度；Fairy 启动动画设置。
全新安装默认关闭自动朗读；已有显式打开的本机偏好不强制覆盖。云端摘要可选，插件不迁移、不内置任何账户密钥。
默认参考音频只在文件缺失时写入 DSH_HOME/fairy-voice-data/runtime/reference，不覆盖已有文件。参考音频不是语音模型权重。

五、启动动画的范围
复用来源包的 startup-default.mp4，保持原始比例，默认完整播放到 ended，可跳过或 ESC 关闭，媒体错误时放行。
这是 DSH 页面加载之后的插件覆盖层，不是 Electron 原生启动窗口替换；不改变原版窗口尺寸，不移植 Fairy 独立启动壳。

六、不会移植的内容
不迁移 Fairy 身份/人格编辑器、角色提示词、语料、Agent 预设、权限全开、沙箱改写、会话重置、历史、账号凭据、独立启动器。不会安装 Python/GPT-SoVITS/大型模型权重，按钮填入提示词也不会绕过原版审批。

七、卸载
完全退出 DSH，双击“卸载插件.cmd”。原版 CLI 将移除 dsh-fairy-ui 插件及其启用项；原版模型与会话不由本脚本删除。
语音数据、参考音频、已下载模型和本机偏好不自动删除，方便保留或后续复用。卸载本界面插件不会自动停止另行部署的语音服务，请使用其自己的停止脚本。

八、交付内容
- dsh-fairy-ui-1.0.0.tgz：正式本地插件包
- 安装插件.cmd / 卸载插件.cmd / install-plugin.ps1：原版 CLI 安装辅助
- checksums.json / SHA256.txt：完整性核验
- 源码：可审计插件代码、依赖与自动测试
- 对比与验证说明.md、验证：范围说明、测试结果与真实界面截图

只对提供的 DSH 0.2.0-rc.2 做了适配与验证，未来版本需要重新核验。遇到安装错误请保留窗口日志，不要直接覆盖 app.asar。
